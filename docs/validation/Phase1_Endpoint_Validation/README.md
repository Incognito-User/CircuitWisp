# Phase 1 Endpoint Validation

This directory contains screenshots captured during the initial validation of CircuitWisp's core API endpoints. These tests confirm that the intelligence pipeline, scoring engine, static modules, and health checks are functioning correctly.

## Included Endpoints
- /config
- /health/sources
- /scorebreakdown/{cve_id}
- /cve/{cve_id}
- /timeline/{cve_id}
- /actors/{cve_id}
- /trending
- /search?q=

Each screenshot demonstrates a successful response from the endpoint.
